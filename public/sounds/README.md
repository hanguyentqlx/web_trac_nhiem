# Âm thanh QuizLab

Đặt 3 file âm thanh vào đúng thư mục này với đúng tên:

- `click.mp3` — âm thanh thao tác/bấm nút
- `correct.mp3` — âm thanh trả lời đúng
- `wrong.mp3` — âm thanh trả lời sai

Sau khi thêm file, không cần sửa JavaScript.

Lưu ý:
- Nên dùng file MP3 ngắn (khoảng 0.1–1.5 giây) để phản hồi nhanh.
- Trên iPhone Safari, âm thanh chỉ được phép phát sau khi người dùng đã chạm vào trang ít nhất một lần.
- Trong phòng thi tắt “Hiện đúng / sai ngay”, web không phát âm đúng/sai để không làm lộ kết quả câu trả lời.
